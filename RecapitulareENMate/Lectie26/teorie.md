# Lecția 26 — Cilindru, con și sferă

## 1. Corpurile rotunde

Cilindrul, conul și sfera sunt corpuri geometrice ale căror suprafețe includ regiuni curbe. Pentru rezolvare, trebuie să deosebești raza, diametrul, înălțimea, generatoarea și apotema și să alegi formula potrivită pentru suprafață sau volum.

## 2. Cilindrul circular drept

Un cilindru circular drept are două baze circulare congruente și paralele, unite printr-o suprafață laterală. Raza bazelor este r, diametrul este `d=2r`, iar distanța dintre planurile bazelor este înălțimea h.

Volumul este `V=πr²h`. Aria bazei este `A_b=πr²`. Suprafața laterală se obține prin desfășurare: un dreptunghi cu lungimea egală cu lungimea cercului `2πr` și lățimea h, deci `A_l=2πrh`. Aria totală este `A_t=2πr²+2πrh=2πr(r+h)`.

## 3. Desfășurarea cilindrului

Desfășurarea unui cilindru este formată din două cercuri și un dreptunghi. Dacă vezi un dreptunghi cu o latură `2πr`, nu o confunda cu diametrul; ea este circumferința bazei.

Pentru r=3 cm și h=10 cm, `V=90π cm³`, `A_l=60π cm²`, `A_t=78π cm²`.

## 4. Probleme inverse la cilindru

Dacă volumul și raza sunt cunoscute, `h=V/(πr²)`. Dacă volumul și înălțimea sunt cunoscute, `r=√(V/(πh))`.

Dacă aria laterală este `40π cm²` și raza este 4 cm, `2π·4·h=40π`, deci h=5 cm.

## 5. Conul circular drept

Un con are o bază circulară și un vârf exterior planului bazei. Raza bazei este r, înălțimea este h, iar generatoarea este g, adică segmentul de la vârf la un punct al cercului bazei.

Într-un con circular drept, axa, raza bazei și generatoarea formează un triunghi dreptunghic:

`g²=h²+r²`.

Volumul conului este `V=πr²h/3`. Suprafața laterală este `A_l=πrg`, iar aria totală este `A_t=πr²+πrg=πr(r+g)`.

## 6. De ce apare factorul 1/3

Un con cu aceeași bază și aceeași înălțime ca un cilindru are volumul egal cu o treime din volumul cilindrului. De aceea `V_con=πr²h/3`. Nu confunda factorul 1/3 cu formula suprafeței laterale; acesta apare numai la volum.

## 7. Generatoarea conului

Dacă raza este 5 cm și înălțimea 12 cm, generatoarea este `√(5²+12²)=13 cm`. Suprafața laterală este `π·5·13=65π cm²`, aria totală `90π cm²`, iar volumul `100π cm³`.

Dacă se cunosc g și r, înălțimea este `h=√(g²-r²)`. Generatoarea trebuie să fie mai mare decât raza.

## 8. Desfășurarea conului

Desfășurarea suprafeței laterale a conului este un sector circular cu raza g. Arcul sectorului are lungimea egală cu circumferința bazei `2πr`. Unghiul sectorului α satisface `α/360·2πg=2πr`, deci `α=360r/g`.

Această relație apare în probleme cu sectoare și permite determinarea unghiului de desfășurare.

## 9. Sfera

Sfera este corpul ale cărui puncte sunt la aceeași distanță r de centru. Orice secțiune prin centrul sferei este un cerc mare cu raza r. Diametrul sferei este `2r`.

Aria sferei este `A=4πr²`, iar volumul este `V=4πr³/3`.

Pentru r=3 cm, aria este `36π cm²`, iar volumul este `36π cm³`.

## 10. Emisfera

O emisferă este jumătate de sferă. Volumul emisferei este `2πr³/3`. Suprafața curbată este `2πr²`. Dacă se cere suprafața totală a emisferei închise, adaugi aria bazei `πr²`, obținând `3πr²`.

Nu confunda suprafața curbată cu suprafața totală. O emisferă deschisă la bază are doar suprafața curbată; una solidă cu baza inclusă are și discul bazei.

## 11. Secțiuni ale corpurilor rotunde

O secțiune a cilindrului perpendiculară pe axă este un cerc cu raza r. O secțiune prin axă este un dreptunghi cu lățimea 2r și înălțimea h.

O secțiune axială a conului este un triunghi isoscel cu baza 2r și laturile g. O secțiune prin centrul sferei este un cerc mare.

Secțiunile axiale reduc problema spațială la una plană și permit folosirea lui Pitagora sau a formulelor de arie.

## 12. Corpuri compuse

Un rezervor poate fi format dintr-un cilindru și două emisfere. Volumul total este suma volumelor, iar suprafața exterioară exclude cercurile de contact dintre componente. Dacă un con este atașat de un cilindru, baza comună nu intră în suprafața exterioară.

Pentru corpuri compuse, desenează componentele, identifică suprafețele interne și externe și adună numai ce se vede la exterior.

## 13. Probleme inverse la sferă

Dacă aria sferei este `100π cm²`, atunci `4πr²=100π`, deci `r=5 cm`. Dacă volumul este `500π/3 cm³`, atunci `4πr³/3=500π/3`, `r³=125`, deci r=5 cm.

Pentru aceeași sferă, raportul dintre arii este pătratul raportului razelor, iar raportul dintre volume este cubul raportului razelor.

## 14. Scări și transformări

Dacă raza și înălțimea unui cilindru se dublează, volumul se înmulțește cu 4, iar aria laterală cu 4. Dacă toate dimensiunile unui con se înmulțesc cu k, volumul se înmulțește cu `k³`, iar suprafețele cu `k²`.

Pentru sfere, dacă raza se triplează, aria se înmulțește cu 9, iar volumul cu 27.

## 15. Conversii și unități

Aria bazei trebuie exprimată în unități pătrate, înălțimea în unități de lungime, iar volumul în unități cubice. Dacă r și h sunt în centimetri, volumul cilindrului este în cm³.

Dacă se cere volumul în litri, folosește `1 dm³=1 L` și `1 m³=1000 L`. Nu transforma doar raza sau doar înălțimea; toate dimensiunile trebuie să fie în aceeași unitate înainte de calcul.

## 16. Greșeli frecvente

1. Confundarea razei cu diametrul.
2. Folosirea formulei cilindrului la con fără factorul 1/3.
3. Folosirea înălțimii în locul generatoarei la aria laterală a conului.
4. Omiterea bazei la suprafața totală a emisferei.
5. Adăugarea cercurilor interne la suprafața exterioară a unui corp compus.
6. Confundarea ariei sferei cu aria discului mare.

## 17. Model integrat

Un con are r=6 cm și h=8 cm. Generatoarea este 10 cm. Volumul este `96π cm³`, aria laterală `60π cm²`, iar aria totală `96π cm²`. Un cilindru cu aceeași bază și înălțime are volumul `288π cm³`, de trei ori mai mare.

## 18. Strategie finală

Identifică r, d, h și g, decide dacă se cere arie curbată, arie totală sau volum, apoi verifică unitățile și suprafețele de contact. Pentru con, construiește triunghiul dreptunghic axial; pentru emisferă, precizează dacă baza este inclusă.

## 19. Comparația dintre cele trei corpuri

Cilindrul, conul și sfera apar frecvent în aceeași problemă, deoarece au formule asemănătoare, dar nu identice. Cilindrul are două baze circulare congruente și o suprafață laterală desfășurabilă într-un dreptunghi. Conul are o singură bază circulară și un vârf; suprafața laterală se desfășoară într-un sector circular. Sfera nu are baze, vârfuri sau muchii și nu poate fi desfășurată exact într-o figură plană simplă.

Pentru cilindru și con, raza bazei apare în aria bazei, deci la pătrat în volumul `πr²h`. Diferența esențială este factorul `1/3` al conului. Pentru o bază și o înălțime comune, volumul conului este o treime din volumul cilindrului. Aceasta este o relație de memorat, dar și de înțeles: conul ocupă doar o parte din cilindrul care are aceeași bază și aceeași înălțime.

Sfera se calculează direct cu raza. Dacă într-un enunț apare diametrul, primul pas este întotdeauna `r=d/2`. De exemplu, pentru `d=10 cm`, raza este `5 cm`, aria este `100π cm²`, iar volumul este `500π/3 cm³`.

## 20. Secțiuni circulare și planuri

O secțiune a unui corp este figura obținută prin intersectarea corpului cu un plan. La cilindru, un plan perpendicular pe axă produce un cerc congruent cu baza. Un plan paralel cu axa poate produce un dreptunghi, dacă intersectează corpul pe toată lungimea necesară. Dacă planul trece prin axă, dreptunghiul are lățimea egală cu diametrul bazei și lungimea egală cu înălțimea cilindrului.

La con, secțiunea prin axă este un triunghi isoscel. Baza lui este diametrul cercului de bază, înălțimea este înălțimea conului, iar laturile egale sunt generatoarele. Din această secțiune se obține relația `g²=h²+r²`, deoarece jumătatea secțiunii formează un triunghi dreptunghic cu catetele `h` și `r`.

La sferă, orice secțiune plană este un cerc. Dacă planul trece prin centrul sferei, se obține cercul mare, cu raza egală cu raza sferei. Dacă planul este la distanța `a` de centru, raza secțiunii `ρ` satisface `ρ²+a²=r²`. Această relație este teorema lui Pitagora aplicată triunghiului format de centrul sferei, centrul secțiunii și un punct de pe cerc.

## 21. Recipiente și nivelul lichidului

Problemele cu recipiente folosesc în special volumul cilindrului. Dacă un recipient cilindric are raza `r` și lichidul ajunge la înălțimea `x`, volumul lichidului este `πr²x`, nu `πr²h` decât dacă recipientul este plin. De aici se poate determina nivelul:

`x=V/(πr²)`.

Dacă se toarnă aceeași cantitate de lichid într-un alt cilindru, nivelul se schimbă invers proporțional cu pătratul razei. Un cilindru cu raza mai mică va avea un nivel mai înalt. Dacă raza se dublează și volumul rămâne constant, înălțimea lichidului devine de patru ori mai mică.

Într-un recipient conic, volumul până la o anumită înălțime nu se calculează ca și cum ar fi un cilindru. Dacă lichidul formează un con asemenea conului inițial, toate lungimile se raportează prin același factor `k`, iar volumul lichidului este `k³` din volumul conului plin. De aceea, dublarea înălțimii lichidului nu dublează volumul, ci îl înmulțește cu 8, dacă și raza secțiunii se dublează prin asemănare.

## 22. Corpuri compuse

Un corp compus se descompune în corpuri cunoscute. O formă de tip „capsulă” poate fi alcătuită dintr-un cilindru și două emisfere. Dacă emisferele au aceeași rază ca cilindrul, cele două emisfere formează împreună o sferă. Volumul exterior este atunci suma dintre volumul cilindrului și volumul sferei:

`V=πr²h+4πr³/3`.

La aria exterioară se adaugă suprafața laterală a cilindrului și aria sferei, dar nu se adaugă cercurile de legătură dintre cilindru și emisfere, deoarece acestea sunt interioare:

`A=2πrh+4πr²`.

Un corp format dintr-un cilindru și un con lipit deasupra are volumul egal cu suma celor două volume. Pentru aria exterioară se consideră aria laterală a cilindrului, aria laterală a conului și, dacă este vizibilă, baza circulară de jos. Cerculețul comun dintre cele două corpuri nu este suprafață exterioară.

Această distincție dintre volum și suprafață este una dintre cele mai importante. La volum, corpurile se adună indiferent de suprafețele de contact. La arie, suprafețele ascunse în interior nu se numără.

## 23. Probleme inverse și ecuații cu π

În problemele inverse, formula se transformă într-o ecuație. Dacă se cunoaște aria laterală a cilindrului, `A_l=2πrh`, atunci `h=A_l/(2πr)` sau `r=A_l/(2πh)`. Dacă se cunoaște aria totală, ecuația poate fi de gradul al doilea în rază:

`A_t=2πr(r+h)`.

Se dezvoltă, se simplifică și se aleg valorile pozitive, deoarece lungimile nu pot fi negative.

Pentru con, dacă se cunosc raza și aria laterală, generatoarea se află din `g=A_l/(πr)`, iar apoi înălțimea se obține din `h²=g²-r²`. Este necesar ca `g>r`; altfel datele nu descriu un con real. Dacă se cunoaște volumul și raza, înălțimea este `h=3V/(πr²)`.

Pentru sferă, din `A=4πr²` rezultă `r=√(A/(4π))`, iar din `V=4πr³/3` rezultă `r=∛(3V/(4π))`. La nivel de examen, rezultatul este adesea ales astfel încât radicalul să fie simplu sau să se poată păstra exact.

## 24. Rapoarte și variația dimensiunilor

Dacă două cilindri au aceeași înălțime, iar razele sunt în raport `k`, volumele sunt în raport `k²`, deoarece `V=πr²h`. Dacă au aceeași rază, volumele sunt în raportul înălțimilor. Pentru con se aplică aceleași reguli, factorul `1/3` fiind prezent la ambele corpuri și simplificându-se în raport.

Pentru sfere, dacă razele sunt în raport `k`, ariile sunt în raport `k²`, iar volumele în raport `k³`. De exemplu, o sferă cu raza de două ori mai mare are aria de patru ori mai mare și volumul de opt ori mai mare.

Aceste relații permit rezolvarea rapidă a unor probleme fără calcul numeric complet. Înainte de a aplica raportul, identifică exact ce se păstrează constant: raza, înălțimea, generatoarea sau forma întreagă.

## 25. Verificare dimensională și estimare

Formula volumului trebuie să conțină trei factori de lungime. În `πr²h`, avem lungime la pătrat înmulțită cu lungime, deci unitatea este cubică. Formula ariei trebuie să conțină două lungimi, ca în `2πrh` sau `4πr²`.

Estimarea este un control util. Dacă `r=3 cm` și `h=10 cm`, volumul cilindrului este aproximativ `3,14·9·10≈283 cm³`. Un rezultat de `28,3 cm³` ar indica probabil pierderea unui factor 10; un rezultat de `2830 cm³` ar indica o înmulțire greșită.

Nu rotunji π prea devreme. Dacă enunțul permite, păstrează forma exactă `12π`, `100π/3` sau `45π`, iar aproximarea zecimală o folosești doar dacă este cerută. Forma exactă reduce erorile și este, de obicei, mai ușor de verificat.

## 26. Model complet de rezolvare

Un corp este format dintr-un cilindru de rază `3 cm` și înălțime `8 cm`, peste care este așezat un con cu aceeași rază și înălțime `4 cm`. Mai întâi calculăm generatoarea conului: `g²=3²+4²=25`, deci `g=5 cm`.

Volumul cilindrului este `π·3²·8=72π cm³`, iar volumul conului este `π·3²·4/3=12π cm³`. Volumul total este `84π cm³`.

Aria exterioară conține aria laterală a cilindrului `2π·3·8=48π`, aria laterală a conului `π·3·5=15π` și baza de jos `9π`. Baza circulară dintre cilindru și con este interioară și nu se adaugă. Prin urmare, aria exterioară este `72π cm²`.

Exemplul arată ordinea corectă: identificarea componentelor, calculul mărimilor auxiliare, volumul prin adunare, apoi aria prin numărarea exclusivă a suprafețelor vizibile.

## 27. Concluzie operațională

Pentru orice problemă cu cilindru, con sau sferă, notează datele cu simboluri, desenează corpul și marchează raza, diametrul, înălțimea și generatoarea. Scrie formula înainte de înlocuirea numerelor. Decide dacă se cere suprafață laterală, suprafață totală, suprafață exterioară sau volum. La corpuri compuse, separă clar corpurile și elimină suprafețele de contact din aria exterioară.

La final, verifică unitatea, semnul, ordinul de mărime și faptul că lungimile sunt pozitive. O soluție bună nu este doar o formulă aplicată, ci un raționament geometric în care fiecare termen are o interpretare clară.
