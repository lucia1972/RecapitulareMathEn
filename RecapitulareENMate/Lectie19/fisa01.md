# Fișa 01 — Date statistice

1. Calculează media numerelor 6, 8, 10, 12.
2. Determină mediana șirului 3, 9, 5, 7, 11.
3. Determină moda șirului 2, 4, 2, 5, 4, 2.
4. Calculează amplitudinea datelor 12, 7, 18, 9, 4.
5. Notele 6, 8, 8, 9, 10 au ce medie, mediană și modă?

## Răspunsuri

1. 9; 2. 7; 3. 2; 4. 14; 5. media 8,2, mediana 8, moda 8.
