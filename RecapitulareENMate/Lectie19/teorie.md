# Lecția 19 — Organizarea și interpretarea datelor

## Obiective

Vei calcula media, mediana, moda și amplitudinea, vei citi tabele și grafice și vei verifica dacă o concluzie este susținută de date.

## 1. Frecvențe

Frecvența unei valori este numărul de apariții. Frecvența totală este numărul tuturor datelor. Un tabel de frecvențe organizează valorile și aparițiile lor.

## 2. Media aritmetică

Media este suma valorilor împărțită la numărul lor: `m=(x₁+...+xₙ)/n`. Dacă valorile au frecvențe, `m=(x₁f₁+...+x_kf_k)/(f₁+...+f_k)`.

## 3. Mediana și moda

Pentru mediană, ordonează datele. La un număr impar de date, este valoarea din mijloc; la un număr par, este media celor două valori centrale. Moda este valoarea cu frecvența cea mai mare.

## 4. Amplitudinea

Amplitudinea este diferența dintre cea mai mare și cea mai mică valoare. Este o măsură simplă a răspândirii datelor.

## 5. Grafice

La grafice verifică titlul, unitatea, scara și legenda. Nu compara înălțimi de bare dacă axa verticală nu începe de la zero sau dacă scara diferă.

## Greșeli frecvente

- uitarea frecvențelor la calculul mediei;
- alegerea medianei înainte de ordonare;
- confundarea modei cu media;
- citirea greșită a scării graficului.

## Autoevaluare

Explică de ce două seturi de date pot avea aceeași medie, dar amplitudini diferite.
