# Lecția 18 — Cilindru, con și sferă

## Obiective

Vei calcula aria și volumul cilindrului, conului și sferei și vei identifica diferența dintre raza bazei, înălțime și generatoare.

## 1. Cilindrul

Cilindrul are două baze circulare congruente și o suprafață laterală. Pentru raza `r` și înălțimea `h`:

`V=πr²h`, `A_l=2πrh`, `A_t=2πr(h+r)`.

## 2. Conul

Conul are o bază circulară și un vârf. Volumul este `V=πr²h/3`. Dacă `g` este generatoarea, aria laterală este `A_l=πrg`, iar aria totală `A_t=πr(g+r)`.

În conul drept, `g²=r²+h²`.

## 3. Sfera

Pentru raza `r`, aria sferei este `A=4πr²`, iar volumul este `V=4πr³/3`.

Diametrul este `2r`; nu îl introduce direct în formule fără conversie.

## 4. Strategie

Identifică corpul, notează datele cu unități, verifică dacă este dat diametrul sau raza, apoi alege formula. Păstrează rezultatul în funcție de `π` dacă nu se cere aproximare.

## Greșeli frecvente

- folosirea formulei cilindrului pentru con fără `1/3`;
- confundarea generatoarei cu înălțimea conului;
- folosirea diametrului drept rază;
- folosirea formulei ariei sferei pentru volumul ei.
