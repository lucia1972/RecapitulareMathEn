# Fișa 01 — Funcții

1. Pentru `f(x)=3x-2`, calculează `f(0)`, `f(2)` și `f(-1)`.
2. Determină intersecțiile graficului lui `f(x)=2x-6` cu axele.
3. Este crescătoare sau descrescătoare funcția `g(x)=-4x+1`?
4. Determină funcția de gradul I care trece prin `(0,3)` și `(2,7)`.
5. Rezolvă `2x+1=7-x` folosind interpretarea grafică.

## Răspunsuri

1. `-2,4,-5`; 2. `(0,-6)` și `(3,0)`; 3. descrescătoare; 4. `f(x)=2x+3`; 5. `x=2`.
