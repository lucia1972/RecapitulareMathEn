# Fișa 01 — Statistică și probabilități: exerciții ghidate

## Problema 1 — Media

Calculează media numerelor 6, 8, 9 și 13.

**Rezolvare:** Suma este 36, iar numărul datelor este 4. Media este `36:4=9`.

## Problema 2 — Mediană și modă

Determină mediana și moda seriei `3,8,5,8,10,8,6`.

**Rezolvare:** Ordonăm: `3,5,6,8,8,8,10`. Mediana este 8, iar moda este 8.

## Problema 3 — Frecvențe

Pentru datele `2,3,2,5,3,2`, construiește tabelul de frecvențe.

**Rezolvare:** 2 apare de 3 ori, 3 de 2 ori, 5 o dată. Totalul este 6.

## Problema 4 — Probabilitate la zar

Care este probabilitatea de a obține un număr mai mare decât 4?

**Rezolvare:** Cazuri favorabile: 5 și 6, adică 2. Cazuri posibile: 6. Probabilitatea este `2/6=1/3`.

## Problema 5 — Două monede

Care este probabilitatea de a obține exact o stemă la două aruncări?

**Rezolvare:** Rezultatele sunt SS, SP, PS, PP. Favorabile sunt SP și PS, deci `2/4=1/2`.

## Problema 6 — Complement

Care este probabilitatea de a nu obține 6 la zar?

**Rezolvare:** `P(6)=1/6`, deci complementul este `1-1/6=5/6`.

## Răspunsuri rapide

1. 9; 2. mediană 8, modă 8; 3. 2:3, 3:2, 5:1; 4. `1/3`; 5. `1/2`; 6. `5/6`.
