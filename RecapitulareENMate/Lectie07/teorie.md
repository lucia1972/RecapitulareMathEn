# Lecția 07 — Sisteme de ecuații

## Obiective

Vei rezolva sisteme de două ecuații cu două necunoscute, vei alege metoda potrivită și vei transforma problemele cu două mărimi necunoscute într-un sistem.

## 1. Ce este un sistem

Un sistem de forma

`a₁x+b₁y=c₁` și `a₂x+b₂y=c₂`

caută perechea `(x,y)` care verifică simultan ambele ecuații. O valoare care verifică o singură ecuație nu este soluție a sistemului.

## 2. Metoda substituției

Izolează o necunoscută într-o ecuație și înlocuiește expresia în cealaltă.

Exemplu:

`x+y=7`, `x-y=1`.

Din prima, `x=7-y`. Înlocuim: `7-y-y=1`, deci `2y=6`, `y=3`, iar `x=4`.

Metoda este convenabilă când un coeficient este 1 sau -1.

## 3. Metoda reducerii

Aduni sau scazi ecuațiile astfel încât una dintre necunoscute să dispară.

Exemplu:

`2x+y=10`, `x-y=2`.

Adunăm ecuațiile: `3x=12`, deci `x=4`. Din `x-y=2`, rezultă `y=2`.

Dacă coeficienții nu sunt opuși, înmulțește una sau ambele ecuații cu numere potrivite.

## 4. Verificarea

După ce ai obținut perechea, înlocuiește-o în ambele ecuații. De exemplu, pentru `(4,2)`, prima ecuație dă `2·4+2=10`, iar a doua dă `4-2=2`.

## 5. Probleme cu sisteme

Pașii sunt:

1. identifică cele două mărimi necunoscute;
2. notează clar ce reprezintă `x` și `y`;
3. traduce două informații din enunț în ecuații;
4. rezolvă sistemul;
5. verifică unitățile și formulează răspunsul.

Exemplu: suma a două numere este 38, iar diferența este 10. Alegem numerele `x` și `y`: `x+y=38`, `x-y=10`. Adunând, `2x=48`, deci `x=24`, iar `y=14`.

## 6. Probleme cu prețuri

Dacă un bilet costă `x` lei și un caiet `y` lei, două bilete și trei caiete costă `2x+3y`. Această traducere este adesea partea dificilă, nu calculul propriu-zis.

## 7. Interpretare geometrică

Fiecare ecuație liniară cu două necunoscute reprezintă o dreaptă. Soluția sistemului este punctul de intersecție. Drepte paralele distincte înseamnă lipsa soluțiilor, iar drepte coincidente înseamnă infinit de multe soluții.

## Greșeli frecvente

- schimbarea semnului unei ecuații doar la un singur termen;
- folosirea unei relații greșite pentru diferență;
- raportarea lui `x` și `y` în ordinea inversă față de enunț;
- neverificarea ambelor ecuații;
- uitarea unităților la problemele cu prețuri sau lungimi.
