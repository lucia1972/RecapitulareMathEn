# Fișa 01 — Calcul numeric ghidat

Rezolvă complet și scrie fiecare etapă.

## Probleme

1. Calculează: `18 - 3 · [4 + 2²] : 3`.
2. Calculează și simplifică: `5/6 - 1/4 + 2/3`.
3. Calculează: `(-3)² - 2³ + | -5 |`.
4. Un produs costă 240 lei și se reduce cu 15%. Care este prețul nou?
5. Compară fără calculator: `3/7 + 2/7` și `4/5`.

## Indicații

- La problema 1, rezolvă mai întâi puterea, apoi paranteza.
- La problema 2, caută cel mai mic numitor comun.
- La problema 3, fii atent la diferența dintre `(-3)²` și `-3²`.
- La problema 4, calculează mai întâi reducerea sau folosește factorul `0,85`.
- La problema 5, adu fracțiile la un numitor comun sau compară prin înmulțire în cruce.

## Răspunsuri scurte

1. `10`
2. `5/4`
3. `6`
4. `204 lei`
5. `3/7 + 2/7 < 4/5`
