# Lecția 17 — Piramide

## Obiective

Vei identifica baza, vârful, înălțimea și apotema unei piramide și vei calcula arii, volume și lungimi în configurații regulate.

## 1. Elemente

O piramidă are o bază poligonală și fețe laterale triunghiulare care se întâlnesc într-un vârf. Înălțimea este perpendiculara din vârf pe planul bazei. Apotema este înălțimea unei fețe laterale regulate și nu trebuie confundată cu înălțimea piramidei.

## 2. Volumul

`V=A_b·h/3`.

Factorul `1/3` este esențial. Pentru aceeași bază și înălțime, piramida are o treime din volumul prismei.

## 3. Piramida regulată

Într-o piramidă regulată, baza este poligon regulat, iar proiecția vârfului este centrul bazei. Fețele laterale sunt triunghiuri isoscele congruente.

Dacă baza este pătrat de latură `a`, `A_b=a²`, iar aria laterală este `P_b·a_p/2`, unde `a_p` este apotema piramidei.

## 4. Lungimi

În triunghiul format de înălțime, apotemă și apotema bazei se aplică Pitagora: `a_p²=h²+r_b²`, unde `r_b` este distanța de la centrul bazei la mijlocul unei laturi.

## Greșeli frecvente

- folosirea înălțimii laterale la volum;
- uitarea factorului `1/3`;
- confundarea apotemei bazei cu apotema piramidei;
- calcularea ariei laterale fără perimetrul bazei.
