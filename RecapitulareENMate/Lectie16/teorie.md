# Lecția 16 — Cub, paralelipiped și prismă

## Obiective

Vei calcula arii, volume și diagonale pentru cuburi, paralelipipede și prisme și vei recunoaște baza și înălțimea în configurații spațiale.

## 1. Cubul

Pentru muchia `a`, cubul are `V=a³`, aria totală `A_t=6a²`, aria unei fețe `a²`, diagonala feței `a√2` și diagonala spațială `a√3`.

## 2. Paralelipipedul dreptunghic

Pentru dimensiunile `L,l,h`:

`V=Llh`, `A_t=2(Ll+Lh+lh)`, iar diagonala este `d=√(L²+l²+h²)`.

Formula diagonalei vine din aplicarea succesivă a teoremei lui Pitagora.

## 3. Prisme

O prismă are două baze congruente și paralele. Volumul este `V=A_bh`. Dacă prisma este dreaptă, aria laterală este `P_bh`, iar aria totală este `P_bh+2A_b`.

## 4. Alegerea bazei

La o prismă triunghiulară, baza poate fi un triunghi, iar înălțimea este distanța dintre bazele triunghiulare. Nu confunda înălțimea prismei cu înălțimea triunghiului din bază.

## Greșeli frecvente

- numărarea greșită a bazelor;
- folosirea ariei bazei în locul perimetrului la aria laterală;
- uitarea unităților cubice;
- folosirea lui `a√2` ca diagonală spațială a cubului.
